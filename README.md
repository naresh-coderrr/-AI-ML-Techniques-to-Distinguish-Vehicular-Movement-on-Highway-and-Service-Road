# MargMatch India

Unified ITS app: live satellite + TomTom traffic map, Kalman GNSS smoothing, and highway vs service-road matching on the Indian network.

```bash
cd india-margmatch
npm install
npm run dev
```

Open http://localhost:5173 — sign up or Google, then use **Instructions** in the sidebar.

Google Cloud: add `http://localhost:5173` as an authorised JavaScript origin for the OAuth web client. Do not put the client secret in the frontend.
